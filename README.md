# SOC Analyst Home Labs

Hands-on cybersecurity lab work documenting practical learning in SIEM, IDS/IPS, and Network Security Monitoring (NSM).

## Projects

### 1. Wazuh SIEM Virtual Lab
Configured a virtual lab with Wazuh and Kali Linux, verified agent connectivity, reviewed test security events in the Wazuh dashboard, and practiced file integrity monitoring.

Folder: [`wazuh-siem-lab/`](wazuh-siem-lab/)

### 2. Suricata IDS/IPS and Zeek NSM
Practiced Suricata installation and configuration, custom rule creation, alert-log review, JSON event filtering with `jq`, and Zeek HTTP/DNS/connection log inspection, including offline PCAP analysis.

Folder: [`suricata-zeek-network-monitoring/`](suricata-zeek-network-monitoring/)

## Tools
Wazuh, Suricata, Zeek, Kali Linux, Ubuntu Server, Docker, VirtualBox, Nmap, and `jq`.

## Scope and ethics
These projects were performed as learning labs. Testing should only be conducted in systems and networks you own or are explicitly authorized to assess. Any screenshots or logs added later should be reviewed for passwords, tokens, personal data, and confidential information.

## Evidence
Each project folder contains a project README and the corresponding lab report provided for documentation. Add screenshots to the `screenshots/` folder only after checking them for sensitive information.
