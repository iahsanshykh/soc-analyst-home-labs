# Wazuh SIEM Virtual Lab — Security Event Monitoring

## Objective
Build a virtual lab to explore Wazuh security monitoring and review events generated by test activity.

## Environment and tools
- Wazuh virtual appliance / dashboard
- Kali Linux
- Oracle VirtualBox
- Virtual networking (NAT network)

## Work performed
- Imported and started the Wazuh virtual appliance in VirtualBox.
- Installed Kali Linux and configured both virtual machines on the same NAT network.
- Checked connectivity between the virtual machines.
- Verified Wazuh services and dashboard access.
- Confirmed that the Kali Linux agent appeared as active in Wazuh.
- Generated SSH-related test activity and reviewed the resulting event in the Wazuh dashboard.
- Practiced file integrity monitoring.
- Ran an Nmap scan as a lab exercise.

## Results
The lab report documents successful virtual-machine connectivity, an active Kali agent, and a test event visible in the Wazuh dashboard. File integrity monitoring and an Nmap scan were also included as exercises.

**Accuracy note:** The report records that an Nmap scan was run; it does not by itself establish that Wazuh detected or alerted on that scan.
